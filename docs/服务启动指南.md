# AI Bot 服务启动指南

本文说明 **Relay 中转**、**PC Agent**、**手机 App** 的启动方式与常用地址。当前生产环境使用明文 WebSocket：**`ws://你的域名/ws`**（无 HTTPS 证书）。

---

## 一、架构与端口

```text
手机 App  ──ws──►  Relay (Nginx:80 → Node:8787)  ◄──ws──  PC Agent (Windows)
                         │
                    SQLite 任务记录
```

| 组件 | 运行位置 | 对外地址 | 本机端口 |
|------|----------|----------|----------|
| Relay | 你的云服务器 `你的服务器IP` | `ws://你的域名/ws` | 127.0.0.1:8787（仅本机） |
| PC Agent | 你的 Windows PC | 主动连接 Relay | 无入站端口 |
| App | Android 手机 | 连接 Relay | — |

健康检查：`http://你的域名/health` 或 `http://你的服务器IP/health`

## 二、远程 Relay（已部署，一般不用本机启动）

服务器：**你的服务器IP**（Alibaba Cloud Linux 3）  
目录：`/opt/grokbot-relay`  
systemd 服务名：`grokbot-relay`

### SSH 登录后常用命令

```bash
# 状态
systemctl status grokbot-relay

# 启动 / 停止 / 重启
systemctl start grokbot-relay
systemctl stop grokbot-relay
systemctl restart grokbot-relay

# 日志
journalctl -u grokbot-relay -f

# 环境变量（含 RELAY_PUBLIC_URL、JWT_SECRET）
cat /opt/grokbot-relay/.env
```

### Nginx

- 配置：`/etc/nginx/conf.d/grokbot-relay.conf`
- 重载：`nginx -t && systemctl reload nginx`

### 从本机重新部署 Relay 代码

```powershell
cd D:\wamp64_332\www\grokbot
$env:GROKBOT_SSH_HOST='你的服务器IP'
$env:GROKBOT_SSH_USER='root'
$env:GROKBOT_SSH_PASS='你的密码'
$env:GROKBOT_DOMAIN='你的域名'
python relay/deploy/upload_deploy.py
```

## 三、PC Agent（Windows，必须常开才能遥控）

Agent 负责在本机执行 `grok` / `claude` / `agent`(Cursor) / `dsh` / `cursor` / `svn`。

### 首次 / 更新代码后

```powershell
cd D:\wamp64_332\www\grokbot
npm install
npm run build                  # 全量：protocol → relay → agent
```

只改了 Agent：`npm run build -w agent`。  
改了协议：`npm run build -w shared/protocol` 后再 `npm run build -w agent`。  
详见 [安装部署指南 §1.2](./安装部署指南.md#12-首次克隆与构建)。

### 开发模式启动（推荐调试）

```powershell
cd D:\wamp64_332\www\grokbot
npm run dev:agent
```

或使用生产构建：

```powershell
npm run agent
```

启动后会：

1. 连接 `agent/agent.config.json` 里的 `relayUrl`（默认 `ws://你的域名/ws`）
2. 控制台打印 **8 位配对码** 与 **二维码**（首次无 token 时）
3. 配对成功后 token 写入 `agent/agent.config.local.json`

### 配置文件

| 文件 | 作用 |
|------|------|
| `agent/agent.config.json` | 工作区白名单、CLI 路径、默认 Relay |
| `agent/agent.config.local.json` | 本地覆盖（含 token，勿提交 Git） |
| 环境变量 `RELAY_URL` | 覆盖 Relay 地址 |

### 开机自启（计划任务）

```powershell
cd D:\wamp64_332\www\grokbot\agent
npm run build
powershell -ExecutionPolicy Bypass -File scripts\install-agent-task.ps1
```

## 四、本地 Relay（仅本地联调时需要）

生产已用远程 Relay，**日常只需启动 Agent + App**。若要在本机自建中转：

```powershell
cd D:\wamp64_332\www\grokbot
copy relay\.env.example relay\.env   # 首次
npm run dev:relay                      # 开发热重载
# 或
npm run relay                          # 运行 dist
```

本机地址：`ws://127.0.0.1:8787/ws`  
此时 Agent 的 `relayUrl` 需改为上述地址。

## 五、手机 App

### 开发运行（USB / 模拟器）

```powershell
cd D:\wamp64_332\www\grokbot\app
flutter pub get
flutter run
```

配对页默认 Relay：**`ws://你的域名/ws`**  
Android 模拟器若连本机 Relay 可改为：`ws://10.0.2.2:8787/ws`

### 安装 Release APK

已打包版本见 **[releases/grokbot_app-1.0.0+1.apk](../releases/grokbot_app-1.0.0+1.apk)**（说明见 [releases/README.md](../releases/README.md)）。

自行打包：

```powershell
$env:GRADLE_USER_HOME="$env:USERPROFILE\.gradle"
cd D:\wamp64_332\www\grokbot\app
flutter pub get
flutter build apk --release
```

产物：`app/build/app/outputs/flutter-apk/app-release.apk`

### 配对步骤

1. 确保 **远程 Relay 已运行**（`systemctl is-active grokbot-relay` 为 active）
2. 在本机启动 **PC Agent**，记下配对码
3. 打开 App → 输入 Relay 地址与配对码（或扫码）→ 配对
4. 选择工作区与工具，发送指令

1. （远程 Relay 已在服务器常驻，可跳过）

## 八、常见问题

| 现象 | 处理 |
|------|------|
| App 配对失败 | 检查 Relay 地址是否为 `ws://`；域名 A 记录是否指向你的服务器IP；安全组是否放行 80 |
| Agent 连上又立刻断开、循环重连 | 本地 token 是旧 Relay 签的，与远程 JWT 不一致：删掉 `agent.config.local.json` 里的 `token` 后重启 Agent，用手机重新配对 |
| 任务 failed（grok） | 本机配置 `GROK_API_KEY` 或 grok CLI 登录 |
| Cursor Agent 无响应 | 本机执行 `agent login` |
| Android 无法 ws | 已开启 `usesCleartextTraffic`；勿填 `wss://` |
